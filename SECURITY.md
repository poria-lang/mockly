# Security Policy

## Supported Versions

We actively provide security patches exclusively for the latest release version of Mockly.

| Version | Supported          |
| ------- | ------------------ |
| v1.x    | ✅ Active Support   |

## Reporting a Vulnerability

**Please do not open public GitHub issues for security vulnerabilities.**

If you discover a security flaw or an input sanitization bypass, please report it privately by sending an email to **your-security-email@example.com**.

### What to Include:

* A detailed description of the vulnerability vector.
* A minimal reproduction config (`mockly.json`) or script.
* Potential remediation paths if known.

We acknowledge all valid security submissions within 48 hours and will coordinate a structured path toward an upcoming patch release.
